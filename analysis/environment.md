# 环境设计

## 观察

环境既是故事发生地，也是悬疑和冒险的线索来源。建筑场景会细画门窗、栏杆、家具、立面装饰和地板；自然场景会区分树干、枝叶、地面、雪、水或岩石。不同卷册中的地点并不相同，不能把某一种古堡、森林或洞穴说成全套插画的固定背景。

环境细节常比人物更密，但人物仍通过清晰轮廓和动作保持可读。第26册第86页的雪村以屋顶、围栏、小路和树木逐层填满画面；第23册第10页利用近景树木和地面植被建立森林包围感。

## 新图应用

选取少量与地点有关的物件作为视觉线索，再按远近安排轮廓和纹理。让环境支持剧情，例如可藏身的门洞、阻挡路径的枝条或延伸到远处的路；避免无差别地给所有表面添加细节。
