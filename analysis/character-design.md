# 人物设计

## 观察

- 人物脸部通常优先保证情绪可读：眉眼、张口或抿嘴等简单变化，配合头部倾斜，就能表达惊讶、紧张、得意或困惑。
- 体型和服饰轮廓有助于快速区分角色。样本里既有圆厚、重心低的人物，也有更细长的少年角色；不应把所有人物套成一种头身比例。
- 姿态承担叙事功能。张开的手、回头、弯腰、迈步等轮廓动作，即使画面缩小也容易看懂。
- 角色小图常用干净背景突出全身轮廓；故事场景则把人物放进复杂环境，人物和背景的线密度可以有意区分。

## 新图应用

先确定角色的体型、发型、衣着轮廓和动作，再补脸部细节。让不同人物通过外轮廓和动作区别开；保留少年冒险故事的亲和力和夸张表情，但避免逐一照搬参考页中的具体角色。
