# 悬疑与轻恐怖表达

## 观察

悬疑效果常由“看见一部分、暂时看不清另一部分”形成：大块阴影、门洞、森林遮挡、巨大异形或远近尺度反差，都能暗示威胁。第1册第106页把逼近的暗影压在逃跑人物身后；第7册第140页用盘绕物体占据空间、人物聚在一侧；第18册第177页则把人物放在广阔洞穴环境里，让周围黑暗和岩层控制气氛。

样本属于少年冒险书中的悬疑图像表达。这里的结论强调紧张感、未知感和奇异感，不把少数黑暗场景概括成血腥恐怖路线。

## 新图应用

- 通过遮挡或负空间留出未知区域。
- 用一个主要威胁形状和少量环境提示代替堆叠惊吓元素。
- 让人物的视线、后退或奔跑方向告诉观者危险在哪里。
- 维持角色表情与动作的可读性；按目标读者年龄控制惊悚程度。
