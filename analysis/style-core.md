# 综合风格核心

## 稳定可见的特征

这批样本最适合概括为“面向少年冒险故事的叙事插画”：人物造型简洁、表情易读，场景承担悬疑线索和气氛；多数正文故事图使用黑白或灰阶，通过清楚的轮廓、明暗块和环境细节组织画面。人物常以夸张姿态表现奔跑、受惊、探索或对峙，周围环境则提供空间和故事信息。

第1册第106页的追逐场景把大块阴影放在左侧、奔跑人物放在右侧，并用门窗和地面线条交代室内纵深；第7册第140页让盘绕的触手占据画面一侧，以小人物作尺度参照；第23册第10页则用近景树干框住向林中奔跑的人群。这些是可复用的构图和叙事手法，不是固定模板。

## 使用时的简要配方

1. 先确定一个容易辨认的动作或情绪。
2. 让人物轮廓和手势在缩小后仍清晰。
3. 用前景、主体和背景建立至少两到三层空间。
4. 用明暗对比突出焦点；复杂细节留给环境或威胁物。
5. 默认黑白正文插画；仅在明确需要时采用彩色封面式表现。

## 证据范围

分析基于27册扫描页和141张人工筛选的代表裁图。扫描清晰度、灰度、印刷和卷册设计存在差异。此处只描述肉眼可见的共同倾向，不据此断言作者身份，也不把某一册、某一张图的特征推广到全部插画。
